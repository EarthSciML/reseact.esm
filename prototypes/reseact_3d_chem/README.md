# reseact_3d_chem — Stage C1: SuperFast lifted onto the GEOS-FP grid

**Status: architecture PROVEN, the full 12-species assembly does NOT yet build.**
One open bug, with a probe ladder that isolates it. Read this before touching it.

## What this is

`reseact_3d_chem.esm` (generated by `gen_c1.py`) patches the verified
`../reseact_3d/reseact_3d.esm` so the whole GEOS-FP forcing chain — verified to
4.1e-10 against the raw netCDF — stays byte-identical, and only chemistry is added:

- **SuperFast mounted BY REFERENCE** (scalar species, exactly as authored);
- a per-species PPM advection contribution on the Transport model, referencing each
  species by SCOPED name, in CWC mixing-ratio form `dq/dt = [-div(M q) + q div(M)]/m`;
- `operator_compose(SuperFast, Transport3D)` with `lifting: "pointwise"`, which merges
  the reaction and advection tendencies and lifts each species onto the grid;
- real GEOS-FP `T` and hybrid mid-layer `P` coupled into SuperFast's scalar `T`/`P`
  params (`param_to_var` carries the grid shape, so the lift indexes them per cell).

Only the **12 non-constant** species are transported. O2/CH4/H2O are `constant: true`
reservoirs with no ODE, so they neither advect nor lift — they broadcast into the rates.

## How this became possible (two changes, both needed)

1. **EarthSciDiscretizations** — dropped the `where {q: {shape: [lon,lat,lev]}}` guard
   from the 9 flux-PPM rules. Rules apply at LOAD; the lift that shapes a 0-D species
   runs later in flatten and only fires if the rule already emitted a `makearray`. That
   was circular, so a reaction species could never be PPM-advected. The `U`/`V`/`W`
   flux-field guard is **kept** — `face_flux_divergence_*` is the same priority (10) and
   also matches `D(Mx*q, wrt)`, so that guard is what stops facediv stealing the match.
   All 111 ESD AST goldens stayed byte-identical.
2. **EarthSciAST `bd3b5519`** — the pointwise lift must skip already-spatial states.
   `m` (`D(m,t) = -(D(Mx,lon)+…)`) was swept in merely because its RHS carries a
   makearray, and it cannot be lifted even in principle.

## The probe ladder (`probes/`) — every ingredient works in isolation

Each probe patches the verified transport model and adds exactly one new thing. All
five PASS, which is what makes the architecture credible:

| probe | adds | result |
|---|---|---|
| `probe6` | reaction system + PPM advection + `lifting:"pointwise"` | **PASS** — 343 cells; interior `B = 0.099502` == exactly `10*(1-e^-0.01)`, i.e. the network runs pointwise per cell |
| `probe7` | + a gridded observed coupled into a reaction-system SCALAR param | **PASS** — B shifts to 0.100119, so the T-dependent rate is live |
| `probe8` | + a nested aggregate (an observed indexing another aggregate, same loop names) | **PASS** |
| `probe9` | + a rank-3 LIVE LOADER gather behind that observed | **PASS** |
| `probe10` | + a rank-4 live loader gather (C1's `Tc` verbatim in structure) | **PASS** |

Run one with e.g. `julia probes/probe6.jl` (they build in ~4 min; they use the Stage-B
ANALYTIC winds deliberately, since the GEOS-FP forcing is verified separately by
`../reseact_3d/probe3.jl`).

## The open bug

The full 12-species `reseact_3d_chem.esm` validates clean (`is_valid=true`) and then
fails during index resolution:

```
ERROR: LoadError: E_TREEWALK_UNBOUND_LOOP_VAR: gj
  _resolve_indices_op  @ tree_walk/resolve.jl:581
```

An `index(X, …, gj, …)` survives outside the aggregate that binds `gj` — i.e. an
observed's aggregate is being inlined into the lifted equation WITHOUT its wrapper,
leaving its `output_idx` loop vars unbound. The reported name tracks whichever loop var
survives (it becomes `gk` once `PS` is made constant), which is the signature of a
systematic inlining problem rather than one bad expression.

**What is ruled OUT** — by the probe ladder above: the lift itself, coupling a gridded
observed into a scalar reaction param, nested aggregates, rank-3 and rank-4 live loader
gathers, and (separately) the GEOS-FP flux observeds — swapping in the analytic
`Mx`/`My`/`Mz` does NOT fix it.

**What is still untested** — the two things real SuperFast has that the toy does not:
1. its rates go through the `arrh_per_molecule` expression template
   (`A*P*exp(B/T)/(8314000*T)`), so EVERY one of the 27 rate expressions carries bare
   `Tc`/`Pc` refs through a template inlining;
2. it has 3 `constant: true` species (O2/CH4/H2O) that have no ODE and so do not lift,
   sitting in a system where the other 12 do.

**Do NOT trust `gen_c1mini.py` as a repro.** It truncates the advected set to 2 species,
which leaves SuperFast's other 10 unlifted (scalar) while their rate expressions
reference the now-array NO/CO — an inconsistent system by construction. It reproduces an
`UNBOUND_LOOP_VAR`, but that may be an artifact of the truncation rather than the real
bug. A valid fast repro needs a genuinely small reaction system, not a truncated one.

## Cost

Build cost tracks RULE INSTANTIATIONS, not cell count — shrinking the grid does not help.
Measured: 9 instantiations = 277 s (analytic winds) / 814 s (GEOS-FP winds). The full
12-species assembly is 39 instantiations, so **~1 h**. One species' RHS expands to 57,688
`index` ops (the PPM re-inlining blowup: no let/sharing node in the Expression AST).

## Known limitations (beyond the open bug)

- **All 12 species share ONE inflow field.** `qbc_{w,e,s,n}` is a FREE NAME in the ESD
  inflow stencils, not a rule param, so there is no way to give O3 a 40 ppb inflow and NO
  a 0.0004 ppb one. Set to clean air (0 ppb) here. A per-species inflow needs `qbc`
  promoted to a rule param. (The EarthSciAST fixture's `grad` rule avoids this by taking
  inflow as an explicit arg: `grad(Chemistry.O3, O3_inflow)`.)
- **The lift picks grid axes by EXTENT.** On the cubic 7x7x7 grid lon/lat/lev are
  indistinguishable, so species land on synthetic `_liftdim1_7`-style axes instead of
  `[lon,lat,lev]` (a warning, not an error — probe6-10 are numerically correct anyway).
  Real fix: take axes from the makearray's index-set references, not a size heuristic.
- **`m` is still the analytic test mass (~2.3 Pa), not physical `dp` (~1400 Pa)** — see
  `../reseact_3d/README.md`. Seed `m(0) = dp` from the runner.
- Everything inherited from Stage A: closed slab top, half-width end lat rows, `m` drifts
  from `dp` (Jockel et al. 2001).
