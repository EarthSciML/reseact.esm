# reseact_3d — Stage A: ReSEACT 3-D transport driven by real GEOS-FP

The verified 7×7×7 monotone-PPM transport stack, now driven by **real GEOS-FP 4×5
meteorology** on a **native CONUS slice — no regridding**.

## What this is

`reseact_3d.esm` is generated by `gen_r3d.py`, which patches the verified
`../transport_3d/transport_3d.esm` so the proven rule stack stays byte-identical and
**only the forcing changes**: the analytic test winds and constant surface pressure are
replaced by GEOS-FP `U`/`V`/`OMEGA`/`PS` (+ `PBLH`, carried for Kzz).

All six discretization rules are imported **by reference** from
EarthSciDiscretizations — regional open-wall inflow BCs on lon/lat, and the hybrid
sigma-pressure massform vertical (`dp = dA[k] + dB[k]·PS(i,j,t)`) on lev.

### Why there is no regridding

The local grid **is** the native grid:

| axis | local | native | note |
|---|---|---|---|
| lon | cells 1..7, centres −110..−80 | `i_nat = 14 + i` | local cell edges land exactly on native cell midpoints, so each local cell has the *same footprint* as native cell 14+i |
| lat | points 1..7, 26..50 | `j_nat = 29 + j` | native lat is point-based (46 points, −90..90 by 4°), matching the exemplar's point-based recipe |
| lev | 1..7 | `k` | k=1 is the surface; no flip |

So the whole conservative-overlap chain collapses to an index shift.

### Time interpolation

Each field comes from an `EarthSciIO.discrete_provider` with `records_per_sample=2`,
returning the two records bracketing the solver time, blended continuously in-model by
`w_time` (the era5 pattern). GEOS-FP's collections are **not co-phased**, so three
independent weights are used — `w_time_I3` / `w_time_A3` / `w_time_A1`, added to
`EarthSciModels/components/earthsci_data/geosfp.esm`:

| collection | fields | cadence | phase |
|---|---|---|---|
| I3 | `PS` | 3 h (instantaneous) | 00:00Z |
| A3dyn | `U`, `V`, `OMEGA` | 3 h (means) | 01:30Z |
| A1 | `PBLH` | 1 h (means) | 00:30Z |

## Verification

Two independent gates, both passing.

**1. Composition + consistency-with-continuity** (`run_r3d.jl`):

```
validate: is_valid=true schema=0 struct=0
simulate: 813.6 s  success=true retcode=Success nstates=1029
  t=18:00Z m in [2.2553, 2.4829] Pa   all positive: true
  +1.0s    m in [2.0674, 2.7092] Pa   all positive: true
CWC GATE  max|q-1| = 0.000e+00   max|dev| = 0.000e+00   -> PASS (bit-exact)
```

**CWC alone is not sufficient evidence** — `q = mq/m ≡ 1` holds for *any* fluxes,
including zero. It gates composition, not the data.

**2. The forcing itself** (`probe3.py` + `probe3_ref.py` + `probe3.jl`) — this is the
gate that proves the data is real. It strips the PPM rules (so the build is ~25 s
instead of ~14 min), leaves the `Mx`/`My`/`Mz`/`PS`/`dp`/`PBLH` expressions intact, and
compares them against a reference computed **independently from the raw netCDF** via
`ncdump`:

```
  probe      model                 reference             rel.err
  pMx          0.000274491928       0.0002744919279   3.84e-10 OK
  pMy        -0.0008470460245      -0.0008470460248   2.71e-10 OK
  pMz          -0.03936956259         -0.0393695626   3.22e-10 OK
  pPS             93609.29993           93609.29997   4.13e-10 OK
  pdp             1403.827919            1403.82792   4.14e-10 OK
  pBL             639.8695324           639.8695322   2.81e-10 OK
  pMxw       -0.0002226298899      -0.0002226298898   3.56e-10 OK   (west WALL face)
  pMys        -0.001232455414       -0.001232455414   3.05e-10 OK   (south WALL face)
```

`pMxw` exercises the wall halo (native cell 14) and `pMys` the lat index clamp, so the
two boundary special-cases are covered, not just the interior. The 4e-10 residual is
Tsit5's tolerance on a slightly ramping integrand, not a modelling error.

Note the probe reference **must** be evaluated at the interval MIDPOINT: the probe
integrates over [T0, T0+1] while `w_time` ramps, so `y(1)−y(0)` is the time-average, not
the value at T0. Evaluating at T0 gives a ~1e-5 "mismatch" that is the test's error, not
the model's — and its size scaling with each collection's cadence (A1 hourly worst) is
itself evidence the time interpolation is live.

## Things that will bite

- **`PS` is hPa in the file** though the loader declares Pa. Everything here scales by
  100. EarthSciIO returns raw file values and applies no conversion.
- **GEOS-FP `U`/`V`/`OMEGA` are cell-centred (A-grid)** in the archived files, despite
  the loader's "edge-staggered" notes. They are averaged to faces here.
- **The subsystem key is `GEOSFP_I3`, not `I3`** — the reference is
  `GEOSFP.GEOSFP_I3.PS`. A wrong key still *runs* and produces plausible numbers with
  the coupling silently unresolved; only `validate()` catches it.
- **The loaders' `url_template` points at the 0.25×0.3125 archive.** The runner supplies
  its own 4×5 URL to `discrete_provider`, which takes the URL directly.
- **t=0 is not runnable.** A1's first record is 00:30Z, so t=0 cannot be bracketed. The
  runner starts at 18:00Z (64800 s), which every collection brackets — and which is
  daytime over CONUS for Stage C's photolysis.

## Known physics limitations (first light, not production)

1. **`m` is still the exemplar's analytic test mass (~2.3 Pa), not the physical `dp`
   (~1400 Pa).** The fluxes are physically sized for the real column, so they move `m`
   ~660× faster than physical. CWC is insensitive to this (it holds for any
   `m(0) = mq(0)`), but the run is not yet physically meaningful. Fix: seed
   `m(0) = dp` from the runner — an `ic()` RHS may not reference an observed.
2. **The 7-level slab is CLOSED at its ~906 hPa top.** `facediv_lev_mass_nf_k1/_kN`
   hardcode the no-flux wall and never read `Mz[1]`/`Mz[NLEV+1]`, so real vertical
   exchange through the model top is suppressed — a truncated-column artifact.
   Negligible over 1 s; not for long runs.
3. **The two end lat rows are half-width** (`lat_edge` clamps them) while native lat
   cells are a full 4°. Confined to the open-boundary rows.
4. **Using `OMEGA` directly means `m` drifts from `dp`** — these are not the mass fluxes
   that reproduce the observed surface-pressure tendency (Jöckel et al. 2001). A
   production CTM derives the vertical flux from the horizontal divergence and the
   surface-pressure tendency instead.
5. **Coverage:** 7 lon cells × 5° = 35°, but CONUS spans ~60°. The slice covers the
   central US (−112.5..−77.5) and misses both coasts; NLON≈12 would contain CONUS.
